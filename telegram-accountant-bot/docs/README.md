## 📣 برای فروش و ارائه (`marketing/`)

| فایل | مخاطب | چیست |
|---|---|---|
| `marketing/brochure-customer.pdf` / `.html` | **مشتری** | بروشور فروش با زبان ساده + قیمت پلن‌ها. آماده‌ی فوروارد یا چاپ |
| `marketing/catalog-features.pdf` / `.html` | داخلی / CTO | کاتالوگ کاملِ فنیِ همه‌ی قابلیت‌ها با وضعیت هرکدام |
| `marketing/pitch-deck.html` | سرمایه‌گذار | پیچ‌دک محصول |

> ⚠️ اگر ویس (`STT_*`) یا خواندن عکس فاکتور (`OCR_*`) را روی سرور تنظیم نکرده‌اید،
> کارت‌های مربوطه را از بروشور مشتری بردارید تا وعده‌ی بی‌پشتوانه ندهید.
